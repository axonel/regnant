# Regnant v1.2.1 — Hyprland Workspace Selector Specification & Architecture

## 1. Overview & Vision

The Regnant Workspace Selector provides an elegant, animated horizontal control surface directly on the Android Home screen (`HomeScreen.kt`), reflecting and driving the first five numbered workspaces (`1 — 2 — 3 — 4 — 5`) of the Omarchy Linux / Hyprland desktop environment.

Rather than being a decorative UI component or polling the host continuously, the integration is:
- **Event-driven**: Connects directly to Hyprland's UNIX domain event socket (`.socket2.sock`) for sub-millisecond, bi-directional workspace synchronization.
- **Bi-directional**: Changes made on the laptop keyboard or trackpad immediately update the phone's visual indicator via WebSocket; touches and swipe gestures on the phone immediately switch the active workspace on the laptop.
- **Omarchy-Native**: Dispatches workspace focus calls through Omarchy's native Lua-based bindings (`o.workspaces.focus(slot)`) with robust fallbacks to `hl.dsp.focus` and `hyprctl dispatch workspace`.

## 2. Linux Hyprland Integration Subsystem

### 2.1 Hyprland Socket2 Event Listener
Located in `linux/host/src/hyprland/manager.js`:
- Connects to `/run/user/<UID>/hypr/$HYPRLAND_INSTANCE_SIGNATURE/.socket2.sock`.
- Automatically reconnects if Hyprland or the socket is reloaded.
- Parses incoming real-time socket lines:
  - `workspace>>{name}`: Emitted when active workspace switches.
  - `workspacev2>>{id},{name}`: Emitted with detailed ID and name.
  - `focusedmon>>{mon},{workspace}`: Emitted when focus changes monitors or workspaces.
- Emits internal `'workspace'` event upon notification, which `server.js` broadcasts over WebSocket to all authenticated Android clients as:
  ```json
  {
    "type": "WORKSPACE_STATE",
    "workspaceId": 3,
    "workspaceName": "3",
    "monitorName": "eDP-1",
    "activeSlot": 3,
    "timestamp": 1731853400000
  }
  ```

### 2.2 Omarchy Dispatcher Syntax
On Omarchy Linux running Hyprland v0.56.2+, raw dispatcher syntax (`hyprctl dispatch workspace 2`) fails with `error: [string "return hl.dispatch(workspace 2)"]:1: ')' expected near '2'` because the shell binds `hyprctl dispatch` to internal Lua dispatchers.

Regnant addresses this by attempting the following cascade in order:
1. `hyprctl dispatch 'o.workspaces.focus(<slot>)'` (Omarchy primary shell binding)
2. `hyprctl dispatch 'hl.dsp.focus({ workspace = "<slot>" })'` (Hyprland Lua API)
3. `hyprctl dispatch workspace <slot>` (Standard upstream Hyprland fallback)

### 2.3 Boundary Enforcement
- Inputs are strictly validated to integer range `1..5`.
- Non-integer or out-of-range dispatch requests are rejected at both API and manager level with HTTP 400 (`Workspace ID must be between 1 and 5`).

## 3. Android UI Architecture & Gesture Handling

### 3.1 Visual Design (`WorkspaceSelector.kt`)
- Styled adhering to the **Sovereign Command** design palette:
  - Background track: `SurfaceDark` (`#11151D`)
  - Border: `Juniper` (`#343723`)
  - Highlight Pill: `Juniper` container with `Leaf` (`#898861`) border
  - Typography: Monospace font for numbers, with subtle `SurfaceBorder` dashes between items (`1 — 2 — 3 — 4 — 5`).
- **Spring-Based Animation**: Uses `animateFloatAsState` configured with:
  ```kotlin
  spring(
      dampingRatio = Spring.DampingRatioLowBouncy,
      stiffness = Spring.StiffnessMediumLow
  )
  ```
  providing an organic, tactile glide across slots without jitter.

### 3.2 Unified Touch & Swipe Gesture Pipeline
To support both instant single-tap activation and horizontal drag-to-select without gesture starvation:
- Uses `pointerInput` with `awaitEachGesture` at the track level.
- **Tapping**: Pointer down followed by pointer up within the drag threshold (dx < 20px) immediately calculates the clicked slot `((x / slotWidth) + 1).coerceIn(1, 5)` and commits `onWorkspaceSelected(slot)`.
- **Swiping**: Pointer movement exceeding 20px activates drag mode (`isDragging = true`). The highlight pill tracks the dragged finger dynamically across slots. Upon finger release (`changedToUp`), the final slot under the finger is committed to the host.
- No drag spam: intermediate dragged states update local UI preview only; the network dispatch is emitted once upon gesture release.

### 3.3 Out-of-Range Workspace Handling
If the workstation transitions to a workspace outside `1..5` (e.g. scratchpad, workspace 6, or named tag):
- The 1..5 numbers are not falsely highlighted.
- The indicator pill transitions to a hidden/dim state.
- The header badge displays `ACTIVE: WS <id>` (in Coral warning tint) instead of `SLOT <n>`, clearly informing the user that an out-of-range workspace is active on the monitor.
- Touching any of `1..5` switches Hyprland back to that standard workspace.
