# Regnant v1.2 — AI Agent Control Centre
## Architecture, Adapters, NDJSON Streaming & Session Management

Regnant v1.2 introduces an **AI Agent Control Centre** that enables the user to monitor, guide, and interact with coding agents running locally on their Linux workstation directly from their Android device.

---

## 1. Design Principles & Anti-Patterns Rejected

1. **Zero External AI Cloud APIs**: Regnant does not embed OpenAI, Gemini, or Anthropic API keys. It does not call cloud LLM endpoints.
2. **Adapter Pattern for Local Tools**: Regnant controls locally installed CLI coding assistants (`agy`, `claude`, `codex`) via standard child process execution (`spawn` with `stdio: ['pipe', 'pipe', 'pipe']`).
3. **Deterministic Stream Parsing**: Agent streaming turns are parsed in real time from stdout/stderr lines (supporting NDJSON protocol format) and broadcast over WebSocket to the mobile client.
4. **Interactive Multi-Turn Sessions**: Agents that support interactive stdin receive follow-up prompts and guidance from the phone without session restarts.
5. **Persistent Session History**: All agent invocations and turns are journaled in SQLite (`agent_sessions` table) with timestamps, token/turn stats, and exit codes.

## 2. Agent Adapters

Located in `linux/host/src/agents/`:

### BaseAdapter (`base.js`)
Abstract base class defining the contract:
- `isAvailable()`: Checks if the CLI binary exists in `$PATH`.
- `startSession(sessionId, workspacePath, prompt)`: Spawns the process with safe array arguments (`shell: false`).
- `sendInput(sessionId, input)`: Writes to the child process's `stdin`.
- `cancel(sessionId)`: Sends `SIGTERM`, falling back to `SIGKILL` after 3 seconds.
- Emits events: `'data'` (chunk/turn text), `'exit'` (code, signal), `'error'`.

### AgyAdapter (`agy.js`)
- **Binary**: `agy` (Antigravity CLI)
- **Invocation**: `agy --non-interactive -p "<prompt>"` in target `workspacePath`.
- **Parsing**: Standard streaming text output forwarded turn-by-turn.

### ClaudeAdapter (`claude.js`)
- **Binary**: `claude` (Anthropic Claude Code CLI)
- **Invocation**: `claude -p "<prompt>" --output-format json`
- **Parsing**: Extracts assistant text blocks, tool invocations, and cost/token summaries.

### CodexAdapter (`codex.js`)
- **Binary**: `codex` (OpenAI Codex CLI)
- **Invocation**: `codex exec "<prompt>"`
- **Parsing**: Handles streaming turn markers and code diff summaries.

## 3. Protocol & REST Endpoints

### REST Endpoints
- `GET /api/v1/agents`: Returns list of supported agents with `available` flag and `displayName`.
- `GET /api/v1/agents/sessions`: Returns list of past and active agent sessions.
- `POST /api/v1/agents/start`: Starts a new agent session.
  ```json
  {
    "agentId": "agy",
    "workspacePath": "/home/roonakyadav/Projects/regnant",
    "prompt": "Run static analysis and report status"
  }
  ```
- `POST /api/v1/agents/input`: Sends guidance or follow-up prompt to an active session.
  ```json
  {
    "sessionId": "agent-1794914000",
    "input": "Proceed with recommended fix"
  }
  ```
- `POST /api/v1/agents/cancel`: Cancels an active agent session.

### WebSocket Events
- Mobile receives `AGENT_OUTPUT`:
  ```json
  {
    "type": "AGENT_OUTPUT",
    "sessionId": "agent-1794914000",
    "data": "Running dart analyze...\nNo issues found!"
  }
  ```

## 4. Mobile Client Interface (`AgentsScreen.kt`)

The Android application provides:
1. **Agent Selector**: Dropdown / chips for `Agy`, `Claude`, and `Codex`.
2. **Workspace Selector**: Quick-picks from registered workstation projects.
3. **Prompt Entry**: Multi-line command/prompt input with send button.
4. **Live Turn Log**: Monospace terminal-style streaming output with auto-scroll.
5. **Session Control**: Cancel button and follow-up input bar.
