# Regnant v1.2 — Architecture & Design Decisions

**Date:** 2026-11-17  
**Status:** Approved for Implementation  
**Release:** Regnant v1.2 Developer Workstation Control Centre

---

## 1. Core Principles Retained
1. **Local-First & Resource-Efficient:** Zero cloud relay, zero external LLMs/AI APIs, zero Antigravity runtime requirements. Regnant controls tools running locally on the user's computer.
2. **Deterministic & Safe Execution:** No arbitrary shell evaluation (`shell: false`, array arguments only). Every command and capability is guarded by the device permission matrix.
3. **Fail-Safe & Recoverable:** WebSocket connections are self-healing. Mobile client handles reconnects cleanly with session resuming.

---

## 2. Architecture Decisions by Subsystem

### 2.1 AI Agent Control Centre
- **Adapter Pattern:** Standardized interface `AgentAdapter` (`detect()`, `startSession()`, `stream()`, `sendInput()`, `cancel()`).
- **Supported Adapters:**
  - `AgyAdapter`: Spawns `agy` with `--output-format stream-json --input-format stream-json`. Emits normalized NDJSON events (`turn_start`, `content`, `tool_use`, `turn_complete`, `error`).
  - `ClaudeAdapter` & `CodexAdapter`: Detect mise shims / binaries; report honest status (`AVAILABLE` vs `NOT_INSTALLED`) and guidance.
- **Persistence:** SQLite table `agent_sessions` storing session ID, agent type, workspace path, prompt, status, PID, start time, end time.
- **WebSocket Streaming:** Message types `AGENT_START`, `AGENT_OUTPUT`, `AGENT_INPUT`, `AGENT_CANCEL`, `AGENT_STATUS`.

### 2.2 Persistent Remote Terminal
- **Native PTY:** `node-pty` spawns `/bin/bash` with `TERM=xterm-256color` in a designated working directory.
- **Session Registry:** Multi-session registry in host memory. Each session maintains a circular output buffer (100 KB) so when the phone reconnects or switches tabs, past terminal output is immediately replayed.
- **Lifecycle:** Client can detach without terminating the shell. Explicit `kill` or process exit destroys the session.
- **Security:** Guarded by `CAPABILITIES.TERMINAL_ACCESS`.
- **WebSocket Messages:** `TERM_CREATE`, `TERM_ATTACH`, `TERM_INPUT`, `TERM_RESIZE`, `TERM_OUTPUT`, `TERM_CLOSE`.
- **Mobile UI:** Custom auxiliary keyboard in Compose providing Tab, Ctrl, Esc, Up, Down, Left, Right, `Ctrl+C`, `Ctrl+D`.

### 2.3 Git & GitHub Cockpit
- **Local Git:** Direct non-shell execution of `/usr/bin/git`:
  - Branches: `git branch --list --all -v`
  - Status: `git status --porcelain=v2 -b`
  - Commits: `git log -n 20 --pretty=format:...`
  - Diff: `git diff --stat` and `git diff`
- **GitHub Integration:** `/usr/bin/gh` wrapper using native JSON flags:
  - PRs: `gh pr list --json number,title,author,state,isDraft,headRefName,baseRefName`
  - PR Details: `gh pr view <number> --json ...`
  - Workflows: `gh run list --json databaseId,name,headBranch,headSha,status,conclusion`
  - Log View: `gh run view <run-id> --log`
- **Zero Credential Extraction:** Runs under the logged-in user environment, relying on existing `gh` keyring authentication.

### 2.4 Window & Workspace Controller (Hyprland)
- **Wayland IPC:** Direct JSON queries to `hyprctl`:
  - `hyprctl -j clients`: Array of open windows (address, title, initialClass, workspace ID).
  - `hyprctl -j workspaces`: Array of active workspaces.
- **Dispatches:**
  - Focus: `hyprctl dispatch focuswindow address:<addr>`
  - Move: `hyprctl dispatch movetoworkspace <id>,address:<addr>`
  - Close: `hyprctl dispatch closewindow address:<addr>`

### 2.5 Browser Tab Controller & Manifest V3 Extension
- **Extension Architecture:** Lightweight Manifest V3 unpacked extension for Brave/Chromium (`linux/browser-extension`).
- **Communication:** Local WebSocket connection on `localhost:53317/browser-bridge` with an extension auth token stored in host config.
- **Capabilities:**
  - List open tabs (id, title, url, active, windowId).
  - Activate tab (`chrome.tabs.update(tabId, { active: true })`).
  - Close tab (`chrome.tabs.remove(tabId)`).
  - Open new tab (`chrome.tabs.create({ url })`).
  - Active page text extraction (on user request only, with length limits).
- **Security:** Restricts origin, requires shared host secret token.

### 2.6 Live Desktop Peek
- **Capture Engine:** Wayland `grim` CLI tool (`/usr/bin/grim -t jpeg -q 70 -`).
- **Zero Disk Overhead:** Streams directly from `grim` standard output to HTTP response stream (`image/jpeg`).
- **Rate-Limiting:** Host enforces minimum 500ms cooldown per client to prevent resource exhaustion.
- **Security:** Guarded by `CAPABILITIES.DESKTOP_PEEK`. Mobile UI provides tap-to-refresh and zoom.

### 2.7 Audio & Media Controller
- **PipeWire / WirePlumber:**
  - Status: `wpctl get-volume @DEFAULT_AUDIO_SINK@`.
  - Volume adjust: `wpctl set-volume @DEFAULT_AUDIO_SINK@ <level>`.
  - Mute toggle: `wpctl set-mute @DEFAULT_AUDIO_SINK@ toggle`.
- **MPRIS D-Bus:**
  - Controlled via `busctl --user call org.mpris.MediaPlayer2.* /org/mpris/MediaPlayer2 org.mpris.MediaPlayer2.Player PlayPause`.
  - Next / Previous / Stop / Metadata retrieval.

### 2.8 Unified Download Manager
- **Sources:**
  - Browser downloads tracked via Extension `chrome.downloads` API.
  - Filesystem inspection of `~/Downloads` for recent downloads and partial download files (`.crdownload`, `.part`).
- **Actions:** Pause, resume, cancel, reveal in file manager.

### 2.9 Universal Laptop Search (SQLite FTS5)
- **Indexing Engine:** SQLite FTS5 table `search_index` (columns: `id`, `type`, `title`, `path`, `keywords`).
- **Sources Indexed:**
  - Registered development projects.
  - Installed desktop applications (`/usr/share/applications/*.desktop`, `~/.local/share/applications/*.desktop`).
  - Approved file roots (excluding `.git`, `node_modules`, `.cache`, build output).
- **Querying:** Sub-millisecond prefix matching with snippet generation.

### 2.10 Event-Triggered Automations & Scheduled Actions
- **Typed Internal Event Bus:** Host event emitter triggering rules on:
  - `DEVICE_CONNECTED`, `DEVICE_DISCONNECTED`
  - `AGENT_COMPLETED`, `AGENT_FAILED`
  - `DOWNLOAD_COMPLETED`
  - `HOST_LOW_BATTERY`
- **Scheduler:** SQLite table `schedules` supporting cron expressions and interval timers. Host checks scheduled tasks on a 30-second heartbeat.
- **Rule Actions:** Launch project, send mobile notification, lock screen, mute audio, run routine.

### 2.11 Wake-on-LAN & Mobile Remote Surface
- **Hardware Integration:** Host inspects `/sys/class/net/` and `iw phy` to report MAC and WoWLAN support.
- **Mobile Sender:** Android client generates standard UDP magic packet (6x `0xFF` followed by 16 repetitions of target MAC) broadcast to `255.255.255.255:9`.
- **Android Widget & Tile:**
  - AppWidget for quick workstation status and favourite routine trigger.
  - Android 7.0+ Quick Settings `TileService` (`RegnantTileService`) for instant connection toggle / sleep / wake.
