# Regnant v1.2 — Live Desktop Peek
## Wayland Native Screen Capture, JPEG Optimization & Mobile Zoom

Regnant v1.2 provides **Desktop Peek**, allowing users to visually check their workstation screen (e.g. build completion, long tests, or modal dialogs) on demand without the heavy overhead, battery drain, and security risks of continuous VNC/RDP streaming.

---

## 1. Native Wayland Capture (`DesktopPeekManager`)

Located in `linux/host/src/peek/manager.js`:

- **Wayland Toolchain**: Captured natively via `grim`, the standard Wayland screen grabber for wlroots and Hyprland compositors.
- **Environment Context**: Inherits `$WAYLAND_DISPLAY` and `$XDG_RUNTIME_DIR` from the user session.
- **Pipeline**:
  1. `grim -t ppm -` streams uncompressed frame data over stdout into memory.
  2. Compresses the frame into a lightweight JPEG buffer using `cjpeg` or `ffmpeg`, with adjustable quality parameter (`q` between 30 and 95, default 70).
  3. Returns binary JPEG payload directly with `Content-Type: image/jpeg` header.
- **Rate-Limiting & Resource Protection**:
  - Minimum 1000ms cooldown between captures to prevent mobile polling from consuming workstation CPU/GPU cycles.
  - Image size is typically 80 KB to 140 KB per capture, ensuring instant transfer over local Wi-Fi.

---

## 2. Protocol & REST Endpoint

- `GET /api/v1/desktop/peek?q=70`:
  - Query parameters:
    - `q`: Compression quality (integer 30-95).
  - Response:
    - Headers: `Content-Type: image/jpeg`, `Cache-Control: no-cache`
    - Body: Raw JPEG binary buffer.

---

## 3. Mobile Client Interface (`DesktopPeekScreen.kt`)

The Android application implements a smooth, high-fidelity viewer using Jetpack Compose:
1. **Pinch-to-Zoom & Pan Gesture Support**:
   - Implements `Modifier.pointerInput` with `detectTransformGestures`.
   - Supports zoom factors from `1.0x` (full screen overview) up to `4.0x` (pixel-level inspection of small terminal fonts or error messages).
   - Dynamic 2D pan offsets bounded to the zoomed viewport dimensions.
2. **Double-Tap / Reset Zoom Button**: Quickly snaps zoom back to `1.0x` and centers the display.
3. **Capture Metadata**: Displays capture timestamp and payload size (e.g., `Captured at 18:40:46 (82 KB)`).
4. **Auto & Manual Refresh**: Pull-to-refresh or tap refresh button to fetch the latest workstation frame.
