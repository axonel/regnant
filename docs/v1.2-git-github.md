# Regnant v1.2 — Git & GitHub Cockpit
## Local Git Inspection, Keyring-Authenticated gh CLI & Remote Safety Model

Regnant v1.2 features a comprehensive **Git & GitHub Cockpit** that enables developers to monitor their codebase's health, review active branches and commit history, inspect working tree diffs, and check GitHub pull requests and workflow runs directly from their phone.

---

## 1. Local Git Subsystem (`GitManager`)

Located in `linux/host/src/git/git.js`:

- **Path Resolution**: Commands accept an optional `?path=` query parameter. If omitted, the host server automatically falls back to the default project repository (`/home/roonakyadav/Projects/regnant`), preventing failures when the background daemon's working directory is `$HOME`.
- **Repository Validation**: Verifies repository existence via `git rev-parse --is-inside-work-tree` before executing inspection queries.
- **Strictly Read-Only Local Queries**:
  - `getStatus(repoPath)`: Executes `git status --porcelain=v1` and `git branch --show-current`, parsing staged, modified, and untracked file counts.
  - `getBranches(repoPath)`: Executes `git branch -a --format='%(refname:short)|%(HEAD)'` to enumerate local and tracking branches.
  - `getCommits(repoPath, limit)`: Executes `git log -n <limit> --pretty=format:'%H|%an|%ae|%at|%s'` to format commit history into structured JSON objects.
  - `getDiff(repoPath)`: Executes `git diff` and `git diff --cached` (bounded to 200 KB) for reviewing uncommitted edits.

---

## 2. GitHub CLI Subsystem (`GitHubManager`)

Located in `linux/host/src/git/github.js`:

- **Zero API Key Storage**: Regnant does not store GitHub Personal Access Tokens or API keys. Instead, it interfaces directly with the official GitHub CLI (`gh`), which uses the Linux desktop's native secret storage / keyring (`gh auth status`).
- **Safe Fallback**: If `gh` is not installed, not authenticated, or offline, the subsystem degrades gracefully, returning `authenticated: false` and friendly guidance without crashing or throwing HTTP 500 errors.
- **Features**:
  - `checkAuth()`: Executes `gh auth status` to detect the logged-in user handle and auth state.
  - `getPullRequests(repoPath, limit)`: Runs `gh pr list --json number,title,state,author,headRefName,url` to return active repository pull requests.
  - `getWorkflowRuns(repoPath, limit)`: Runs `gh run list --json id,name,status,conclusion,headBranch,url` to monitor CI status.

---

## 3. Remote Safety Model

To prevent accidental data loss or unauthorized modifications from mobile:
1. **Read-Only Inspection**: In v1.2, remote Git operations are strictly read-only (`status`, `branches`, `commits`, `diff`, `pr list`, `run list`).
2. **No Unauthenticated Shell Injection**: Commands are invoked using array-argument subprocess spawns (`execFile('git', args, ...)` with `shell: false`).

---

## 4. Mobile Client Interface (`GitHubScreen.kt`)

The Android application provides:
1. **Repository & Branch Header**: Displays current branch name (`feature/v1.2-control-centre`), commit hash, and dirty tree badges.
2. **File Change Counters**: Visual counters for Modified, Staged, and Untracked files.
3. **Commit Log**: Scrollable timeline of recent commits with author name, relative timestamp, and commit message.
4. **GitHub Integration Card**: Shows authenticated GitHub handle (`@roonakyadav`) with badges for active PRs and CI workflow statuses.
