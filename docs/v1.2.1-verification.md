## 2. Verification Test Matrix

| # | Test Scenario | Execution Step | Expected Result | Actual Result | Status |
|---|---|---|---|---|---|
| **TC-01** | **Initial Workspace Synchronization** | Launch app on phone while laptop is on Workspace 2 | Workspace selector renders `1 — 2 — 3 — 4 — 5` with pill on Slot 2 | Slot 2 indicator highlighted with spring animation | **PASS** |
| **TC-02** | **Bidirectional Sync from Laptop to Phone** | Switch to Workspace 3 using laptop keyboard (`hyprctl dispatch 'o.workspaces.focus(3)'`) | Hyprland `.socket2.sock` fires; host transmits `WORKSPACE_STATE`; phone updates without polling | Indicator instantly animated to Slot 3; badge updated to "SLOT 3" | **PASS** |
| **TC-03** | **Phone Touch Tap Workspace Switch** | Tap Slot 1 on Android touch screen | Phone sends switch request; Hyprland switches to workspace 1 | Hyprland switched to `id: 1`; phone animated to Slot 1 | **PASS** |
| **TC-04** | **Standard Slot Progression** | Tap Slot 4, then Slot 5 on Android screen | Hyprland switches to workspace 4, then 5 | `hyprctl activeworkspace` verified 4 and 5; phone synchronized | **PASS** |
| **TC-05** | **Lock Laptop Modal Trigger** | Tap `[ 🔒 Lock Laptop ]` button in telemetry banner | Confirmation dialog opens displaying target machine name and security notice | Dialog displayed `Lock electron (Omarchy)?` with explicit security text | **PASS** |
| **TC-06** | **Lock Dialog Dismissal (Cancel)** | Tap "Cancel" button on confirmation dialog | Dialog closes; laptop remains unlocked | Dialog dismissed cleanly; laptop remained active | **PASS** |
| **TC-07** | **Remote Lock Execution** | Tap "Lock" button in confirmation dialog | Host invokes `/usr/share/omarchy/bin/omarchy-system-lock`; screen locks; phone shows toast | `omarchy-shell lock isLocked` returned `true`; Android showed `"Laptop locked"` | **PASS** |
| **TC-08** | **Host Persistence When Locked** | Inspect host daemon after workstation lock | Host daemon remains active on port 53317 with open WebSocket | `systemctl --user status regnant-host` active and healthy | **PASS** |
| **TC-09** | **Security Boundary Verification** | Verify absence of remote unlock APIs or password storage | No password stored in Android Keystore or host SQLite; no unlock endpoint | Verified code and endpoints: strictly one-way lock | **PASS** |
| **TC-10** | **Unit & Regression Tests** | Run `npm test` in `linux/host/` | All desktop and workspace unit tests pass | **31/31 passed** (100%) | **PASS** |
