# Regnant v1.2 — Browser Tab Controller
## Manifest V3 Extension, Local Loopback WebSocket Bridge & Mobile Tab Management

Regnant v1.2 introduces the **Browser Tab Controller**, allowing the user to view open browser tabs, activate specific tabs, close unnecessary tabs, open new URLs, and safely inspect active page content from their phone.

---

## 1. Extension Architecture (`linux/browser-extension/`)

Built as a Chromium/Brave **Manifest V3** extension adhering to modern web extension security standards:

- **Manifest**: `manifest.json`
  - Permissions: `tabs`, `activeTab`, `storage`, `downloads`.
  - Host Permissions: `http://localhost:53317/*`, `ws://localhost:53317/*`.
- **Background Service Worker**: `background.js`
  - Connects to the Regnant Linux Host via local WebSocket loopback: `ws://127.0.0.1:53317/browser-bridge`.
  - Authenticates using an extension bearer token generated during installation and stored in `chrome.storage.local`.
  - Implements automatic reconnection with exponential backoff if the host service restarts.
  - Handles bidirectional commands:
    - `GET_TABS`: Uses `chrome.tabs.query({})` to enumerate all open tabs across windows (id, windowId, title, url, active, favicon).
    - `ACTIVATE_TAB`: Calls `chrome.tabs.update(tabId, { active: true })` and `chrome.windows.update(windowId, { focused: true })`.
    - `CLOSE_TAB`: Calls `chrome.tabs.remove(tabId)`.
    - `OPEN_TAB`: Calls `chrome.tabs.create({ url })`.
    - `INSPECT_PAGE`: Uses `chrome.scripting.executeScript` to extract active page title, meta description, and top-level headings on user request.
    - `DOWNLOAD_EVENTS`: Listens to `chrome.downloads.onCreated`, `onChanged`, and `onDeterminingFilename` to forward download progress to the host.

---

## 2. Linux Host WebSocket Bridge (`BrowserManager`)

Located in `linux/host/src/browser/manager.js`:

- **Dedicated Bridge Route**: `GET /browser-bridge` on port 53317 upgrades to WebSocket.
- **Connection State**: Tracks whether the browser extension is currently active and connected.
- **Safety**: If the browser extension is disconnected, REST endpoints return graceful status (`connected: false`, empty tabs) rather than hanging or failing.

---

## 3. Protocol & REST Endpoints

- `GET /api/v1/browser/tabs`: Returns array of open browser tabs.
- `POST /api/v1/browser/activate`: Switches focus to specified tab.
  ```json
  { "tabId": 14205, "windowId": 1 }
  ```
- `POST /api/v1/browser/close`: Closes specified tab.
  ```json
  { "tabId": 14205 }
  ```
- `POST /api/v1/browser/open`: Opens a URL in a new tab.
  ```json
  { "url": "https://github.com" }
  ```
- `GET /api/v1/browser/inspect`: Returns text summary of currently focused page.
