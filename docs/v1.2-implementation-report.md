## 1. Executive Summary

Regnant v1.2 transforms Regnant from a basic remote launcher into a full-featured **Developer Workstation Control Centre**.

Operating strictly on a local-first, zero-cloud architecture, Regnant connects an Android mobile device (Vivo I2407, Android 16) directly to a Linux workstation (Omarchy Linux, Hyprland, Wayland, PipeWire) over local Wi-Fi.

### What Was Built:
1. **AI Agent Control Centre**: Adapter-based orchestration for locally installed coding assistants (`agy`, `claude`, `codex`) with NDJSON streaming turns and multi-turn interactive input.
2. **Persistent Remote Terminal**: Native interactive PTY (`node-pty`), 100KB circular scrollback buffer, WebSocket streaming, and a mobile auxiliary virtual keyboard (`Tab`, `Ctrl`, `Esc`, `Ctrl+C`, `Ctrl+D`, arrow keys).
3. **Git & GitHub Cockpit**: Local git inspection (branch, log, diff, staged/modified/untracked counters) plus keyring-authenticated `gh` CLI inspection for active PRs and CI workflow runs.
4. **Window & Workspace Controller**: Hyprland IPC bridge (`hyprctl`) for listing clients, switching workspaces, and focusing or closing application windows.
5. **Browser Tab Controller**: Chromium/Brave Manifest V3 web extension with loopback WebSocket bridge (`ws://127.0.0.1:53317/browser-bridge`) for remote tab listing, tab switching, opening/closing URLs, and page inspection.
6. **Live Desktop Peek**: On-demand Wayland screen capture via `grim`, JPEG compression, and mobile gesture support (pinch-to-zoom up to 4.0x, 2D pan).
7. **Audio & Media Controller**: PipeWire/WirePlumber (`wpctl`) volume and sink controls; MPRIS media player controls via D-Bus (`busctl`).
8. **Unified Download Manager**: Local `~/Downloads` inspection combined with browser extension download tracking.
9. **Universal Laptop Search**: SQLite FTS5 full-text index across project directories, desktop application files (`.desktop`), and approved roots.
10. **Event-Triggered Automations**: Typed event bus (`DEVICE_CONNECTED`, `AGENT_COMPLETED`, etc.) with cooldown deduplication and SQLite storage.
11. **Scheduled Actions**: Persistent heartbeat scheduler running recurring interval tasks and one-off timers.
12. **Quick Settings Tile & AppWidget**: Native Android `TileService` (`RegnantTileService`) and home screen AppWidget (`RegnantWidgetProvider`).
13. **Wake-on-LAN / WoWLAN**: Network adapter hardware inspection (`iw phy`, `wlp0s20f3`, MAC `28:a0:6b:45:90:9d`) and UDP magic packet sender.

## 2. Architecture & Design Principles

### Local-First, Zero-Cloud Core
- **No External LLM APIs**: No OpenAI, Gemini, or Anthropic API keys embedded or called.
- **No Runtime Antigravity Requirement**: Antigravity is strictly an implementation tool; the runtime has zero Antigravity dependencies.
- **No Cloud Relays**: Direct local TCP/IP networking (IPv4 and link-local IPv6 dual-stack) on port `53317`.

### Sovereign Command Design Theme
Strict adherence to the Sovereign Command visual system across both Android (Jetpack Compose) and Linux desktop:
- Main Background: Deep obsidian (`#0C0F14`)
- Surface Cards: `#1B202A` with border `#262C38`
- Text Primary: Candle ivory (`#EFE9D7`)
- Text Secondary: Muted silver (`#8A94A7`)
- Primary Accent: Sage leaf (`#898861`)
- Warning / Destructive Accent: Coral red (`#7D2826`)

### Concurrency & Data Persistence
- **SQLite with WAL Mode**: `PRAGMA journal_mode = WAL; PRAGMA busy_timeout = 5000;` prevents database lock contention between background scheduler ticks, event triggers, and concurrent REST requests.
- **Lazy Database Proxy**: `dbManager` employs an ES6 Proxy pattern ensuring database initialization occurs cleanly on first access.
